# PeakMiner with MinerDesk

MinerDesk **0.7.39** adds [PeakMiner](https://github.com/peakminer/peakminer) to mining profiles and engine filters on Windows and Linux x64.

1. Create or duplicate a stopped profile and choose **PeakMiner**.
2. Click **Download from GitHub**, or browse to `peakminer.exe` / `peakminer`. The downloader obtains the official Windows ZIP or Linux archive directly from `peakminer/peakminer`, checks the GitHub asset's SHA256 digest before extraction, and selects the original executable. PeakMiner is proprietary and is not bundled or redistributed with MinerDesk; its own license and developer fee apply.
3. For Pearl, enter **`pearlhash`**, **`pearl`** or **`PRL`** in Algorithm. MinerDesk translates these to `--coin pearl`. For Quantus use **`quantus`**, `QTC` or `QUAN`. Other documented coin names are `btx`, `csd`, `midstate` / `MDS`, `alphanumeric` / `ALP`, and `parano1d` / `NOID`; availability depends on the engine version, GPU and operating system. `sha256d` is accepted as an alias for CSD.
4. Enter the pool URL and **public** receiving address/login exactly as the pool documents. PeakMiner receives the login unchanged, including a `.worker` or `/worker` suffix and any merged-payout formatting you explicitly configure. A separate Worker is also passed, but PeakMiner ignores it when the login already contains a dot or slash. No wallet seed or private key is needed.
5. Start with **All GPUs** and blank tuning fields. PeakMiner has no documented standalone device-list command in the interface reviewed. System adapter indices remain informational. Under **Manual IDs / diagnostics**, use IDs confirmed in PeakMiner's console, either numeric indices (`0,2`) or PCI addresses (`01:00.0,0000:03:00.0`). Never mix the two forms in one profile; duplicate aliases are rejected.
6. Configure **Shared GPU settings** only when needed. Core/memory locks use MHz, offsets signed MHz, power watts and fan percent. The mappings are `--gpu-lcore`, `--gpu-lmem`, `--gpu-core`, `--gpu-mem`, `--gpu-power` and `--gpu-fan`. MinerDesk does not add an OC preset. Clear old per-card overrides before changing shared values; conflicting imported values are rejected. For different settings on different cards, use separate profiles or the engine's documented per-index flags in Advanced arguments after confirming its own IDs. An operating-system index is not a verified PeakMiner OC index.
7. Save, start and inspect pool authorization and accepted shares in the console. Stop before editing and restarting. Existing MinerDesk schedules and [reviewed Linux root authorization](LINUX-ELEVATION.md) apply. Changing commands or updating MinerDesk requires renewing unattended root approval; no administrator password is stored.

## API, logs and advanced options

When an API port is set, MinerDesk passes `--api-port 127.0.0.1:PORT`. An unset/zero port passes `--api-port 0`, avoiding the miner's default fixed-port collision. API write controls are not enabled. The dashboard uses console metrics; the read-only engine API remains available locally for other tools. MinerDesk requests a 10-second console status interval, plain text and no periodic usage tips.

PeakMiner is a GPU engine, so the CPU-mining checkbox is hidden. Fan control, thermal thresholds, failover pools, power percentages, OC profiles and other engine-specific options may be entered in Advanced arguments following the [official CLI reference](https://github.com/peakminer/peakminer#cli-reference). Guided power fields use watts. Native engine schedules are separate from MinerDesk schedules; avoid configuring both unless you intend both constraints. Advanced arguments are excluded from unattended root approval.

MinerDesk voluntary support remains **0% by default**, separate from PeakMiner's own fee. PRL and Quantus support slices preserve your embedded worker suffix, separate Worker, pool and GPU settings. Other PeakMiner coins do not infer a donation network from the wallet's appearance.

The adapter was checked against the official **PeakMiner 2.20.0** documentation and verified Windows/Linux downloads. Linux `--help` / `--version` ran successfully. The validation host's Windows application-control policy blocked PeakMiner with error 4556 (malicious binary reputation), so its Windows executable was not run successfully there. Check the exact Windows protection/policy event and the publisher's official release if this happens; MinerDesk does not alter security policies. Tests cover argument boundaries, coin aliases, GPU selectors, cleared/conflicting tuning, download integrity, lifecycle and root authorization. No compatible live GPU benchmark is claimed.
