# MinerDesk 0.7.39 — PeakMiner integration

Choose **PeakMiner** directly in a mining profile and download its official Windows/Linux package from GitHub. The adapter maps Pearl/Quantus and the engine's other documented coin names, pool login, password, worker, GPU selection and shared clock/memory/offset/power/fan settings. `pearlhash` is translated to PeakMiner's `--coin pearl`.

Downloads are checked against the GitHub asset's SHA256 digest before extraction. PeakMiner's API binds to loopback, is disabled without a configured port, and does not enable write controls. Plain console output feeds dashboard metrics. PeakMiner itself is downloaded directly from its publisher and is not bundled with MinerDesk.

Use **All GPUs** or numeric/PCI IDs confirmed in the miner console. PeakMiner does not document a standalone GPU-list command, so system indices are informational. Shared tuning rejects conflicting inherited per-card settings; no OC preset is supplied by MinerDesk. Existing schedules and reviewed Linux root mode apply; renew unattended root authorization after the app update or a command change.

Optional PRL/Quantus support remains at 0% by default and preserves embedded worker suffixes. PeakMiner's developer fee and license are separate. Validation covers command generation, integrity checks, controlled process start/stop/restart and root approval boundaries; no live GPU performance benchmark is claimed.

See the [PeakMiner guide](https://github.com/jontechlabs/MinerDesk/blob/main/docs/PEAKMINER.md).
