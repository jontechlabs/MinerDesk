# MinerDesk 0.7.24 — Update when you're ready

MinerDesk now checks for new stable releases and lets you choose when to install them.

- Checks shortly after startup and every 6 hours while the interface is open; switch automatic checks off or check manually in Settings.
- A new-version banner with release notes, GitHub downloads and a 24-hour snooze. Downloads and installation always require your confirmation.
- In-app updates for the installed Windows x64 application, writable Linux AppImages, and installed Linux Debian packages with graphical administrator approval. Other installations and the headless/LAN dashboard show the GitHub download link.
- HTTPS downloads with verified update signatures. Mining continues during download; MinerDesk stops miners/backend only after verification and restarts after installation.
- Saved profiles, wallet addresses, schedules and downloaded engines are preserved. Unsaved edits must be saved first. Manual mining sessions need to be started again; saved schedules may resume automatically.

**Getting started:** older releases do not contain the updater. Install 0.7.24 once from this release; subsequent versions can notify and update you from inside MinerDesk.

**Downloads:** Windows installer `MinerDesk_0.7.24_x64-setup.exe`, Windows portable ZIP, Linux `.deb`, AppImage, portable Linux archive, headless Windows CLI, and source ZIP. Verify downloads against `SHA256SUMS.txt`.

**Signature status:** installer/AppImage/Debian updater packages have cryptographic update signatures, checked against MinerDesk's embedded public key. Windows Authenticode remains unsigned while the submitted SignPath Foundation application is under review. Update signatures do not remove Windows SmartScreen warnings or administrator prompts. No macOS/ARM packages are provided.
