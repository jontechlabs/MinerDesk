# MinerDesk 0.7.27 — Show Linux SRBMiner's actual mining errors

Linux SRBMiner can suppress console output when stdout/stderr are ordinary pipes. In previous versions, a mining session could exit with code 1 while MinerDesk's console showed only the launch command. This release extends the terminal capture introduced for GPU discovery in 0.7.26 to live SRBMiner sessions.

- Capture Linux SRBMiner's stdout and stderr through separate pseudo-terminals and remove ANSI color sequences before showing logs and parsing metrics.
- Keep the same executable, arguments, working directory, profile data and manual/scheduled ownership. No shell, automatic retry, GPU renumbering or clock/power changes are introduced.
- Display a plain numeric exit code and point users to the miner console instead of the Rust `Some(1)` representation.
- Document power-limit units and a diagnostic test with default GPU tuning. `--gpu-plimit0 2100` requests **2,100 watts**, while a desired fixed 2,100 MHz core clock belongs in **Core clock MHz** (`--gpu-cclock0`). Clear both per-GPU and legacy fallback tuning when testing default settings.

**Validation:** Linux regression fixtures exercise terminal-only stdout/stderr, colored initialization errors with no final newline, nonzero exit status, live hashrate parsing and manual restart/stop. Existing Windows process protection and pipe capture remain in place; CI builds and tests both platforms. Fixtures do not connect to pools or perform real mining. The affected Lubuntu rig is not accessible, so this release improves diagnostics rather than claiming to repair an unconfirmed driver or algorithm problem.

**If mining still fails:** save the profile with clocks, power limit and fan values blank, then retry. Inspect the console's actual SRBMiner messages and **Manual IDs / diagnostics**. GPU IDs must come from that engine's `--list-devices` output. See the [GPU troubleshooting guide](https://github.com/jontechlabs/MinerDesk/blob/main/docs/GPU-SELECTION.md) and [SRBMiner's official parameters](https://github.com/doktor83/SRBMiner-Multi/blob/master/Parameters).

**Downloads:** Windows x64 installer, portable package and headless CLI; Linux x64 Debian package, AppImage and portable archive; source ZIP, SHA-256 checksums and signed updater manifest.
