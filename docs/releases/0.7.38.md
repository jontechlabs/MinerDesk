# MinerDesk 0.7.38 — OneZeroMiner integration

Choose **OneZeroMiner** directly in your mining profiles and download its standalone Windows/Linux package from the official GitHub repository. The adapter supports pool/wallet/password/worker fields, numeric device selection, shared GPU clocks and signed offsets, power/fan settings, local API configuration and advanced arguments. Existing PRL/QTC voluntary support and reviewed Linux root scheduling also apply.

OneZeroMiner does not document a standalone device-list command. System GPU inventory remains informational: use All GPUs or numeric IDs confirmed in its console. GPU tuning uses shared defaults; conflicting inherited per-card overrides report a clear error rather than guessing a device order. No preset clocks are applied. API binding is local-only, an unset API port disables it, and optional engine telemetry is disabled.

See the [OneZeroMiner setup guide](https://github.com/jontechlabs/MinerDesk/blob/main/docs/ONEZEROMINER.md). Engine algorithms, third-party fees, driver requirements and tuning support depend on the installed OneZeroMiner version and GPU. Validation uses controlled process fixtures; no live GPU mining benchmark is claimed.
