# MinerDesk 0.7.28 — Reliable Linux desktop backend startup

After an in-app Linux update, the desktop could open while its built-in backend stayed offline. A short overlap with the previous process could occupy the API port; startup tried once and discarded the error.

- Retry an occupied desktop API port for up to eight seconds during restart, with only one startup worker per desktop instance.
- Record startup and binding errors in backend diagnostics. Start backend can retry the built-in Linux/macOS server without administrator privileges.
- Show Desktop backend on Linux/macOS. Windows scheduled-task repair and restart controls are displayed only on Windows, with the correct executable path in diagnostics.
- Keep native startup responsive and use the backend's configured port when reconnecting.

Mining profiles, wallets, GPU IDs and tuning settings are preserved. This release does not change GPU drivers or mining-engine compatibility. Windows downloads remain unsigned with Authenticode; updater signatures are provided separately.

If 0.7.27 is already offline after an update, fully quit MinerDesk and launch it again to restore its built-in server, then check for this update. Linux `.deb` installation still requires the normal system authorization prompt.
