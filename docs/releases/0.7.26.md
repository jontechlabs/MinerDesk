# MinerDesk 0.7.26 — Readable Linux controls and clearer GPU setup

Fixes unreadable mining-engine dropdowns reported on Lubuntu and a five-second interface timeout that could leave the **Executable** field empty while a managed miner finished installing in the background.

- Render dark select controls with a visible arrow, keyboard focus and readable option colors; request a dark native control theme.
- Allow up to five minutes for an engine download to complete and fill its installed executable path. Upstream requests have bounded connection/download timeouts. No automatic retries are added.
- Show actionable GPU discovery messages for an empty/missing executable, launch error, timeout, failed device listing or unrecognized output. Exact OS and loader errors remain in **Manual IDs / diagnostics**.
- Separate captured stdout and stderr before reading engine GPU rows. Preserve saved profiles, IDs and tuning; system NVIDIA indices remain informational for SRBMiner and other indexed engines.

**Linux GPU setup:** the NVIDIA driver recognizing a card does not verify the IDs used by SRBMiner. Choose the Linux miner executable with **Browse**, or use **Download from GitHub**, wait for the path to appear, then **Refresh** and save. Select `SRBMiner-MULTI`, not its folder or a Windows `.exe`. If the miner still cannot list devices, inspect **Manual IDs / diagnostics** and run that executable with `--list-devices` from its own directory.

**Validation:** regression tests cover a download longer than five seconds, preservation of engine IDs, empty/missing paths, Linux permission/architecture errors and shared-library failure output. The reported Lubuntu rig has not been accessed or upgraded during this release; its exact remaining runtime error, if any, requires the device-listing output. No claim is made that a detected system GPU is usable by a particular algorithm.

**Downloads:** Windows x64 installer, portable package and headless CLI; Linux x64 Debian package, AppImage and portable archive; source ZIP, SHA-256 checksums and signed updater manifest. Windows Authenticode signing remains pending provider acceptance; update signatures are separate.
