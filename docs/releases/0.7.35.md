## Schedule-aware starts and Windows in-app updates

**Start, Restart and Start all now respect your profiles' enabled schedules.** Restarting a miner at 10:00 in a 07:30–15:45 window keeps the 15:45 stop. Outside its windows, the profile waits for the next one.

- Use **Force mining** for an explicit session without a time limit, and **Resume schedule** to return to the planner. Clear badges and English/French messages distinguish scheduled, paused, waiting and forced sessions.
- Keep manual Stop pauses, overlapping/overnight windows and end-of-window sleep/hibernate confirmation. Profiles without an enabled assigned schedule still start immediately. See the [scheduling guide](https://github.com/jontechlabs/MinerDesk/blob/main/docs/SCHEDULING.md).
- Fix the missing Windows **Update…** button when a valid installation is registered in HKLM's 32-bit `WOW6432Node` view. MinerDesk checks both registry views and still requires the registration to match the executable you launched.

**Windows users seeing only GitHub downloads:** install `MinerDesk_0.7.35_x64-setup.exe` once, then reopen MinerDesk from the Start menu. Older affected versions cannot offer this corrective update themselves. Future newer releases can use **Update…** with confirmation and administrator approval. Portable copies continue to use the download page.

Windows and Linux packages are built from the same revision. Application-update signatures are independently verified; Windows Authenticode signing remains pending provider configuration. This release does not change antivirus protection or restore quarantined third-party miners.

Validation includes schedule boundaries, actual fake-miner stop/start/restart, forced/resumed sessions, overlapping windows, bilingual controls, both Windows installation registry views and portable-copy rejection, plus existing Linux privileged-process supervision tests. No live mining profiles or security policies are changed by the tests.
