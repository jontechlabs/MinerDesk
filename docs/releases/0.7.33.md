## Linux GPU tuning with administrator rights

MinerDesk 0.7.33 adds **Run this miner as administrator (root)** to each Linux mining profile. Enable it below GPU tuning, save and click Start. Approve the system's password dialog to let the miner apply supported GPU or memory clocks, offsets and power settings that require administrator access.

The option is off by default. The MinerDesk interface and backend stay under your normal user account. No administrator password is stored and no permanent sudoers or polkit authorization rule is installed.

- Stop and Restart control the root miner's process group, including worker processes. A backend exit or crash closes its private control pipe and stops the group.
- Live terminal output, arguments with spaces and the real miner exit code are preserved.
- Cancelled approval, a missing authentication agent and the 120-second approval deadline produce actionable errors.
- Debian, AppImage and the portable Linux archive include the matching minimal supervisor. Keep the portable archive's three executables together.

Launch MinerDesk from your Linux desktop session. The system needs `pkexec` and a graphical polkit agent. Approval may be requested again for restarts, scheduled starts and voluntary-support wallet switches. Root does not make unsupported GPU/driver tuning settings available. See the [Linux administrator guide](https://github.com/jontechlabs/MinerDesk/blob/main/docs/LINUX-ELEVATION.md).

Windows executables are rebuilt from the same revision; Windows update and backend behavior are unchanged. Windows Authenticode signing remains pending provider configuration. The update packages retain their verified application-update signatures.

Validation includes frontend controls, Rust regression tests, root supervision with disposable fake miners, and compiled-backend Start/Restart/Stop plus forced backend exit. No real GPU clocks or production mining profiles were changed during these tests.
