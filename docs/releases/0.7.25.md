# MinerDesk 0.7.25 — Select the right GPU on mixed rigs

Fixes GPU discovery on machines with both AMD/OpenCL and NVIDIA/CUDA adapters. SRBMiner can number the integrated AMD adapter `GPU0` and an NVIDIA card `GPU1`, even when `nvidia-smi` calls the NVIDIA card `0`. MinerDesk now displays the IDs reported by the mining engine.

- Parse current SRBMiner device listings with backend/device and PCI fields before the name, while preserving older listing formats and sparse IDs.
- Show system adapters as reference information when an indexed engine's selectors cannot be verified. These fallback IDs cannot be selected or used for per-GPU tuning through the device picker; manual IDs remain available.
- Allow 75 seconds for GPU discovery in the interface. Engine diagnostics have a 60-second limit, drain both output pipes and run outside the HTTP request workers. Ignore late results after switching profiles or engines.
- Preserve saved profiles, GPU IDs, tuning, wallet addresses and schedules. Existing GPU selections are not automatically remapped between engines.

**After changing hardware:** open **Miners → your profile → Refresh**, wait for discovery, select the intended card by name and PCI address, then save. SRBMiner IDs can differ from lpminer/CUDA IDs. If detection fails, check **Manual IDs / diagnostics** and use the IDs from the selected engine's own device listing.

**Updates:** version 0.7.24 can notify you about this release and install it after confirmation on supported desktop installations. The LAN/headless interface provides a GitHub download link. Install the update on the mining machine and restart the affected mining profile.

**Downloads:** Windows x64 installer/portable package and headless CLI; Linux x64 Debian package, AppImage and portable archive; source ZIP; SHA-256 checksums and cryptographic update signatures. No macOS or ARM packages are provided. Windows Authenticode signing remains pending SignPath review; update signatures do not remove SmartScreen warnings.

**Validation:** regression tests include the observed AMD-integrated/RTX 5060 Ti listing, old and sparse IDs, PCI extraction, per-GPU clock arguments, fallback-selection guards and bounded diagnostics. The corrected GPU1 configuration was independently confirmed mining Pearl on an RTX 5060 Ti with accepted shares. That live configuration check used 0.7.24; it is not a claim that the newly built binaries were installed or benchmarked on that rig.
