# MinerDesk 0.7.37 — unattended Linux root mining

Scheduled root mining on Linux no longer needs an administrator at the keyboard for every start. A new per-profile **Authorize scheduled starts** flow records narrowly scoped command approval without saving an administrator password.

- Review the launch commands locally, then approve once with Linux. The miner and supporting files are copied into private root-owned storage and the approval is bound to the enrolling Linux account.
- Schedules, restarts and optional support switches use only those approved commands. A changed executable, launch configuration or MinerDesk version requires fresh approval. Missing/revoked approvals leave the profile stopped with a clear error, instead of opening a password dialog from the scheduler.
- **Revoke and stop this miner** withdraws the approval and stops its root process group. Debian uninstall removes the persistent integrations; upgrades preserve records for cleanup and require enrollment again.
- Interactive root mode remains available for manual starts. Windows behavior is unchanged. Advanced arguments, scripts and symlinks are excluded from unattended mode.

After updating on Lubuntu: open the mining profile, enable root mode, choose **Authorize scheduled starts**, review and validate with Linux, then click **Start** to resume this occurrence. The application stays under your normal account. A password change does not revoke the saved command permission; use **Revoke** if that is your intention.

Validation includes UI consent/command binding, source/library fingerprints, account isolation, unsafe-file rejection, cancellation, revocation of a running root fixture, schedule error reporting and existing miner lifecycle checks. Controlled fake miners are used; no live GPU mining benchmark is claimed.
