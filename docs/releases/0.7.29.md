# MinerDesk 0.7.29 — GitHub downloads open in your browser

The desktop's **GitHub downloads** buttons previously did nothing on Windows and Linux. They now open the MinerDesk release page in your default browser, from the update banner, Settings and update error panel. The browser dashboard keeps normal link navigation. If your browser cannot be launched, the address and error are displayed so you can copy it manually.

Linux Debian updates now distinguish cancelled administrator approval, unavailable authorization and package-manager failures. The installer reports its exit code and diagnostic output instead of a generic failure. Authentication remains handled by the operating system, and installation runs outside the interface's async worker.

If an update launched from an SSH-started desktop fails to show an administrator prompt, fully quit MinerDesk, reopen it from your desktop's Applications menu and retry. If graphical authorization remains unavailable, download the `.deb` and install it with `sudo apt install ./MinerDesk_0.7.29_amd64.deb`.

Profiles, wallets, schedules, GPU IDs and tuning settings are preserved. Restart manual mining sessions after updating. Windows downloads remain unsigned with Authenticode; the separate update signatures verify downloaded updates.
