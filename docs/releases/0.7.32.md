# MinerDesk 0.7.32 — Restore Windows in-app updates

Installed Windows copies could show **GitHub downloads** without an **Update…** button. The NSIS installer stores `InstallLocation` with surrounding quotes; MinerDesk previously treated those quotes as part of the directory name and incorrectly classified the installation as portable.

- Read the Windows installation registration directly, without launching PowerShell, and accept quoted or unquoted absolute paths.
- Keep the check that the running desktop belongs to the registered installation. A portable copy cannot update a different installed copy.
- Explain how to enable in-app updates when the copy is portable or its installation registration cannot be verified.
- Add path, native Windows registry and interface regression tests. Linux update behavior is unchanged.

## One-time Windows installation

If your current version has no **Update…** button, download **MinerDesk_0.7.32_x64-setup.exe**, close MinerDesk, run the installer, then launch MinerDesk from the **Start menu**. Your profiles, schedules and downloaded engines are preserved. When a newer release becomes available, use **Settings → Application updates → Check now**, then **Update…** and confirm **Download, install & restart**. Windows can request administrator approval. Manual mining must be restarted after installation.

Portable ZIP builds and browser dashboards continue to provide a download link only. The fix does not require editing the registry or running the desktop as administrator.

Windows executables are still unsigned with Authenticode, pending signing-provider setup. The update packages have separate cryptographic signatures; these do not remove SmartScreen or application-control restrictions.

## Downloads

- Windows x64 NSIS installer, portable ZIP and standalone CLI.
- Linux x64 Debian package, AppImage and portable desktop/CLI archive.
- Source ZIP, signed update manifest, signature files and SHA-256 checksums.

Validation includes frontend tests, Windows/Linux Rust tests and builds, Windows native registry fixtures and update signature/tamper checks. No live mining or unattended installation is performed by these tests.
